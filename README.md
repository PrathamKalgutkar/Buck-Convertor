Buck Convertor designed for IIT Madras's EE4102 - "Electronic Product Design" Course Project
Contained in the Repository are the KiCAD project Files, CSV file for Bill of Materials and PDF File of Final Report submitted to Course Instructor

The Project consisted of :
- Design of Buck Convertor
- Derivation of Component Values
- Design of Circuit Schematic
- Design of DRC checked PCB Board
- 3D View of the Designed PCB
- Estimation of Convertor Efficiency
- Bill of Materials
